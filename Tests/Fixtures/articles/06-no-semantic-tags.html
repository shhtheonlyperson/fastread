Notes on Tooling

Good tools disappear in the hand. They feel like an extension of intent rather than a separate thing that needs to be operated, and you only notice them when something forces you out of flow.

The corollary is that bad tools advertise themselves. Every dialog box, every loading spinner, every unexplained error is the tool reminding you that it exists, and that you are working for it as much as it is working for you.

Designers of small utilities should aim for the first kind. Make the common path quiet, even if that means the rare path is noisy, because the common path is where the user's life actually happens.
