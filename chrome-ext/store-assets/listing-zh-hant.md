# JustRead — Web Store 上架文案（繁體中文）

## 名稱 (≤ 75 字元)

`簡讀 — 閱讀模式 + 速讀`

## 簡短說明 (≤ 132 字元)

`去除網頁雜訊，把文章變成乾淨的閱讀視圖，並以 RSVP 速讀。淺色／深色、襯線／無襯線、h/j/k/l 鍵盤快捷鍵。`

## 詳細說明 (≤ 16,000 字元)

簡讀（JustRead）把任何網頁文章變成一個乾淨、無干擾的閱讀視圖，並讓你能一次一個字、以速讀方式吸收內容。

**兩種模式，一套鍵盤：**

• **閱讀模式** — 移除廣告、側欄、橫幅、留言區，以及所有其他干擾元素。只留下文章本身，置於安靜、講究的排版欄位中。淺色／深色主題、襯線／無襯線字型可選；字級、行高、欄寬都可調整。

• **速讀模式（RSVP）** — Rapid Serial Visual Presentation，逐字快速呈現。一次一個詞，置於最佳識別點上，眼睛不需要左右掃描。每分鐘 150 到 1200 字之間自由調節。可跳句、暫停、回退。整套流程全鍵盤操作（vim 風格的 h/j/k/l，加上方向鍵與空白鍵）。

**為什麼簡讀不一樣：**

• 由雙語閱讀者打造。Tokenizer 原生處理英文與繁體中文，對漢字採用「節奏感分塊」演算法 — 因此「黃士旗」會被當作一個 chunk、「我去吃飯」會切成自然節奏、英文單字也不會被詭異地拆斷。

• 支援 SPA 渲染的網頁。大部分閱讀模式擴充功能在 Substack notes、Medium 草稿等 JavaScript 動態渲染內容上會失效；簡讀對這類頁面有後備擷取策略：當 Readability 找不到內容時，會選取最密集的文字區塊（ProseMirror、文章狀的容器等）。

• 無帳號、無伺服器、無分析追蹤。一切在瀏覽器內運作，原始碼公開。

**速讀模式鍵盤快捷鍵：**

• `空白鍵` — 播放／暫停
• `h` 或 `←` — 上一句
• `l` 或 `→` — 下一句
• `j` 或 `↓` — 變慢（−25 WPM）
• `k` 或 `↑` — 變快（+25 WPM）
• `Esc` — 返回閱讀模式；再按一次 `Esc` 結束

**全域開啟：**

• `Alt+R` — 切換閱讀模式
• `Alt+Shift+R` — 切換速讀模式
• 或點工具列圖示。

**隱私：** 零網路請求、零遙測、零第三方腳本。簡讀只把使用者偏好設定存在 `chrome.storage`，從不把頁面內容傳送到任何地方。完整政策：https://www.theonlyperson.com/privacy
